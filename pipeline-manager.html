How to get a PAT:
  1. Go to github.com/settings/tokens
  2. Click "Generate new token" (Fine-grained)
  3. Set expiration, select axos-financial as resource owner
  4. Under "Repository access" pick "Only select repositories" → select Axos.QE.TestIM (and Axos.QE.Mobile if you want Mobile pipelines too)
  5. Under "Permissions" → "Repository permissions":
      • Actions: Read-only
      • Checks: Read-only
      • Contents: Read-only
  6. Click "Generate token" and paste it above
Token is stored in your browser's localStorage only. Never sent anywhere except api.github.com.
