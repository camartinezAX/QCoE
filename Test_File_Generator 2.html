Identity documents are sample cards for fictional people with drawn photos, clearly marked SPECIMEN, for testing upload and capture flows only. To hit the requested size exactly, padding is appended after the image data (PNG/JPEG), added as an extra RIFF chunk (WebP), placed in an XML comment (SVG), stored as an unused stream object (PDF), packed as an extra binary part inside the ZIP (DOCX), kept in an ignorable RTF group (DOC), or added as trailing whitespace (TXT/CSV/JSON) — every file stays valid and opens normally. Note: .doc files use Word's RTF format inside, which Word opens natively. Files above 1 GB take a few seconds and use temporary disk space; the browser limit is 4 GB.
