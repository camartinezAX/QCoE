Use these if you want to auto-discover pipelines by folder path instead of adding URLs individually. Leave empty to use URLs only.

      

        
Organization URL
          iThe root URL of your Azure DevOps organization.

Example: https://bofaz.visualstudio.com

This is auto-filled from your pipeline URLs, but you can override it here.
        

        
      

      

        
Project Name
          iThe Azure DevOps project name.

Example: Automation Architecture

This is auto-filled from your pipeline URLs.
        

        
      

      

        
Path Filter (Regex)
          iA regular expression to match pipeline folder paths in Azure DevOps.

Example: \\01 Mobile\\(Android|iOS)\\0[1-9]

This matches any pipeline inside folders like:
• \01 Mobile\Android\01 Login
• \01 Mobile\iOS\03 Transfers

Leave empty if using URLs.
        

        
      

      

        
Name Filter (Regex)
          iOptional regex to further filter by pipeline name or path.

Example: sanity|regression

This only keeps pipelines whose name or path contains "sanity" or "regression". Use | to match multiple terms.

Leave empty to include all matches.
