✅ Quick setup (required)
Appfigures only allows browser API calls from https://appfigures.com, so this dashboard needs a tiny local proxy. You’ll run it in your terminal (macOS uses zsh) and keep it running while you use this page. On Windows, use PowerShell + Python or WSL.
1) Start proxy 2) Connection = Local proxy 3) Paste PAT
Click “Copy proxy command”, paste into your terminal, and keep it running. If you see Address already in use, change the port and try again.
macOS: Terminal (zsh). Windows: PowerShell + Python (or WSL). Linux: bash/zsh.

Connection settings

Use Local proxy and set the URL to where your proxy is running (default http://127.0.0.1:8787).
Don’t paste it into chat. If you enable “Remember PAT”, it will be stored in localStorage on this machine. Rotate the token if it was exposed.
