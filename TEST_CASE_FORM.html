🎨 Figma MCP Setup Guide
💡

Why is this needed?

To automatically extract UI component data from Figma designs (buttons, fields, states, constraints), the Figma MCP must be configured in Cursor. Without it, Figma links will still be detected but the AI won't be able to read the design data — it will list the links for manual review instead.

⚠️

Access requirement

Your Figma account must have access to the design files referenced in the PBI. If your account can't view a design in Figma, the MCP won't be able to read it either.

1

Generate a Figma Personal Access Token

Go to Figma → click your avatar (top-left) → Settings → Security tab → Generate new token

Name it something like Cursor MCP

2

Enable ALL permission scopes

For full access to design data, check all boxes — scroll down to see all available scopes:

✓ current_user:read
✓ file_content:read
✓ file_metadata:read
✓ file_comments:read
✓ file_comments:write
✓ file_versions:read
✓ file_variables:read
✓ file_variables:write

Scroll down and check any additional scopes you see (webhooks, dev_resources, etc.). Check everything for full access.

3

Copy the token immediately

The token is only shown once — copy it right away before closing the dialog.

4

Paste your token and generate the prompt

Paste the token you just copied, then click Generate Prompt to get a ready-to-use Cursor chat prompt:

✅ Paste this in Cursor chat — the AI will configure your Figma MCP automatically.

💡 Alternative: Figma also offers a remote MCP server at https://mcp.figma.com/mcp that uses OAuth instead of a personal token — but that requires a different setup flow. Ask the AI for help if you prefer this option.
